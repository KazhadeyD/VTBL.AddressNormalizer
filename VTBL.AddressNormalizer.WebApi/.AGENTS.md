# Каталог: VTBL.AddressNormalizer.WebApi

## Назначение
ASP.NET Core 5.0 HTTP-хост: endpoints, middleware, NLog, options; ядро через `AddAddressNormalizer()` + `IAddressNormalizationService`.

## Файлы

### Program.cs
**Классы:**
- `Program` — точка входа; NLog (`ClearProviders` + `UseNLog`), `UseStartup<Startup>`

### Startup.cs
**Классы:**
- `Startup` — DI: `BatchOptions`, Controllers + `ApiExceptionFilter`, Swagger, `AddAddressNormalizer()`, `IAddressNormalizationService` → `AddressNormalizationService`, ASP.NET Core HealthChecks (`self`, `address_normalizer_readiness`); pipeline: `CorrelationIdMiddleware` до routing + `MapHealthChecks("/health", "/health/live")`

### appsettings.json
Секции `Batch:MaxItems` (default 100) и `NLog` (console + file в `C:\inetpub\logs\VTBL.AddressNormalizer.WebApi\`; layout с `${mdlc:item=CorrelationId}`; Microsoft.* → Warn+, остальное → Info+)

## Подкаталоги
- `Controllers/` — v1: Normalize / Unit / Address (только через IAddressNormalizationService)
- `Health/` — `AddressNormalizerReadinessHealthCheck`, JSON writer для `/health*`
- `Filters/` — MVC filters
- `Middleware/` — Correlation Id + RequestLogging (HTTP status)
- `Models/` — DTO запросов/ответов
- `Mapping/` — IndoorValueMapper → IndoorValueDto
- `Services/` — IAddressNormalizationService + AddressNormalizationService (DI)
- `Options/` — typed configuration

## Зависимости
- `VTBL.AddressNormalizer.Abstractions`
- `VTBL.AddressNormalizer.Infrastructure`
- Packages: `NLog.Web.AspNetCore`, `Swashbuckle.AspNetCore`
