# Каталог: VTBL.AddressNormalizer.WebApi/Health

## Назначение
HealthChecks-инфраструктура WebApi: readiness/liveness проверки и единый JSON-формат ответа health endpoints.

## Файлы

### AddressNormalizerReadinessHealthCheck.cs
**Классы:**
- `AddressNormalizerReadinessHealthCheck` — readiness-проверка:
  - `Batch:MaxItems > 0`
  - синтетический вызов `IAddressNormalizationService.NormalizeUnit("КВ 1")`
  - `Healthy/Unhealthy` с описанием и exception при сбое

### HealthCheckResponseWriter.cs
**Классы:**
- `HealthCheckResponseWriter` — JSON writer для `/health` и `/health/live`
  - поля: `status`, `totalDurationMs`, `checks`
  - по check: `status`, `description`, `durationMs`, `error`

## Зависимости
- `Microsoft.Extensions.Diagnostics.HealthChecks`
- `Services/IAddressNormalizationService`
- `Options/BatchOptions`
